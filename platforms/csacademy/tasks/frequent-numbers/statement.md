# Frequent Numbers

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/frequent-numbers/](https://csacademy.com/contest/archive/task/frequent-numbers/)  

---

You are given an array of $N$ integers and another integer $K$. How many numbers appear in the array at least $K$ times?

### Standard input

The first line contains two integers $N$ and $K$.

The second line contains $N$ integers, representing the elements of the array.

### Standard output

Print the answer on the first line.

### Constraints and notes

$1 \leq K \leq N \leq 1000$ The array elements are integers between $1$ and $1000$ 

| Input | Output |
| --- | --- |
| 3 1<br>1 1 1 | 1 |
| 5 2<br>1 2 3 2 1 | 2 |
| 6 3<br>1 2 2 3 3 3 | 1 |
