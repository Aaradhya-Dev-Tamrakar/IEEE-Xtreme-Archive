# Prime Factors

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/prime-factors/](https://csacademy.com/contest/archive/task/prime-factors/)  

---

You should guess a number $N$ by asking queries of the type:

For a chosen prime number $P$, how many times does $P$ occur in the prime factorization of $N$?

### Interaction

You can start asking your queries right away. Each query should consist of the character Q followed be a prime $P$.

After each query read the answer given by the interactor.

When you are done, print the character A followed by the answer.

### Constraints and notes

This task is NOT adaptive$1 \leq N \leq 10$You can ask at most $5$ queries
