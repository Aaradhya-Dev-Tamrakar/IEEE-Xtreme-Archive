# Squarish Rectangle

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/squarish-rectangle/](https://csacademy.com/contest/archive/task/squarish-rectangle/)  

---

You have a rectangle of width $W$ and height $H$. Both $W$ and $H$ are integers. You want to find another rectangle having the same area such that its sides also have integer lengths, but their absolute difference is as small as possible.

### Standard input

The first line contains two integers $W$ and $H$.

### Standard output

Print a single number representing the minimum absolute difference between the lengths of a rectangle with the same area.

### Constraints and notes

$1 \leq W, H \leq 10^6$

| Input | Output | Explanation |
| --- | --- | --- |
| 12 2 | 2 | The chosen lengths are $(4, 6)$. View |
| 42 6 | 4 | View |
| 9 4 | 0 | View |

21264
