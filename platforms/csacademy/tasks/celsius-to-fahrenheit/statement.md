# Celsius to Fahrenheit

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/celsius-to-fahrenheit/](https://csacademy.com/contest/archive/task/celsius-to-fahrenheit/)  

---

You are given an integer $C$ representing a temperature measured in Celsius degrees. Find the value of $C$ in Fahrenheit degrees, and print it with no decimals.

### Standard input

The first line contains an integer $C$.

### Standard output

Print the value of $C$ in Fahrenheit in on the first line of the output, with no decimals.

### Constraints and notes

$-89 \leq C \leq 54$

| Input | Output | Explanation |
| --- | --- | --- |
| 0 | 32 |  |
| 10 | 50 |  |
| 54 | 129 | The highest natural temperature at ground level on Earth was 54 °C (129 °F) in Kuwait. |
| -89 | -128 | The lowest natural temperature at ground level on Earth is −89.2 °C (−128.6 °F) in  Antarctica |
