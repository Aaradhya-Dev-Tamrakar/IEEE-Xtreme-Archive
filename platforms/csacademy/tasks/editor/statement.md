# Editor

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/editor/](https://csacademy.com/contest/archive/task/editor/)  

---

You have a list of $N$ words, for each word $i$ you know its length $L_i$. You also have a screen of width $W$ and height $H$.

You start typing the words, separated by a single space. If a word doesn't fit on the current line, it will become the first word on the next line. If you finish typing all the $N$ words, you start again from the beginning of the list.

You type the words until you fill all the $H$ lines of the screen (no words can be typed without starting a new line). What is the number of times you typed the first word in the list?

### Standard input

The first line contains three integers $N$, $W$ and $H$.

The second line contains $N$ integers representing the lengths of the words.

### Standard output

Print the answer on the first line.

### Constraints and notes

$1 \leq N \leq 10^5$ $1 \leq W, H \leq 10^9$ $1 \leq L_i \leq W$
