# All Numbers

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/all-numbers/](https://csacademy.com/contest/archive/task/all-numbers/)  

---

You have $N$ decimal digits. Find the sum of all the numbers you can make using all the digits. Numbers with leading $0$s should be discarded from the sum.

Print the answer modulo $10^9+7$.

### Standard input

The first line contain an integer $N$.

The next line contains $N$ digits $D_1, D_2, \ldots, D_N$.

### Standard output

Print the answer on the first line.

### Constraints and notes

$1 \leq N \leq 50$ $0 \leq D_i \leq 9$ for $1 \leq i \leq N$
