# Two Coins

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/two-coins/](https://csacademy.com/contest/archive/task/two-coins/)  

---

You are given $N$ coins, where the $i$-th coin has a value of $v_i$, for each $i$ between $1$ and $N$. How many different amounts can you pay using exactly 2 coins?

### Standard input

The first line contains an integer $N$, the number of coins.

The second line contains $N$ integers representing the values of the $N$ coins.

### Standard output

Print the answer on the first line of the output.

### Constraints and notes

$1 \leq N \leq 10$ $1 \leq v_i \leq 10$, for each $i$, where $1 \leq i \leq N$ 

| Input | Output | Explanation |
| --- | --- | --- |
| 4<br>2 2 1 3 | 3 | The amounts that can be paid are: 3, 4 and 5 |
