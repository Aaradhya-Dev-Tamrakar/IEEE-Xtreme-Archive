# Neighbour Sum Replacement

**Time Limit:** `1500 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/neighbour-sum-replacement/](https://csacademy.com/contest/archive/task/neighbour-sum-replacement/)  

---

You are given a circular array of $N$ integers. You need to replace each element by the sum of its neighbours. Output the resulting array.

### Standard input

The first line contains a single integer $N$.

The second line contains $N$ values representing the elements of the array.

### Standard output

The first line of the output should contain a single integer $N$.

The second line should contain $N$ integers representing the resulting array.

### Constraints and notes

$3 \leq N \leq 1 000$The elements of the array are integers between $1$ and $1 000$

| Input | Output |
| --- | --- |
| 3<br>1 2 4 | 3<br>6 5 3 |
| 4<br>4 9 1 3 | 4<br>12 5 12 5 |
| 5<br>3 2 3 1 3 | 5<br>5 6 3 6 4 |
| 6<br>1 3 5 4 4 5 | 6<br>8 6 7 9 9 5 |
