# Frequency Exception

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/frequency-exception/](https://csacademy.com/contest/archive/task/frequency-exception/)  

---

You are given an array of $N$ integers. Each distinct value occurs the same number of times, with the exception of exactly one value. Find this value.

### Standard input

The first line contains a single integer $N$.

The second line contains $N$ integers representing the elements of the array.

### Standard output

Print a single integer representing the value that occurs a different number of times than all the rest.

### Constraints and notes

$4 \leq N \leq 1000$ There are at least $3$ distinct values in the arrayThe elements of the array are integers between $0$ and $10^9$

| Input | Output |
| --- | --- |
| 5<br>1 1 2 2 3 | 3 |
| 5<br>0 1 2 4 4 | 4 |
