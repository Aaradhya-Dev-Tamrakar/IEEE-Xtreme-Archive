# Unicorns

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/unicorns/](https://csacademy.com/contest/archive/task/unicorns/)  

---

In the land of fairy tales is located a magic garden with 3 types of animals

chickens, having $2$ legs and no hornsrams, having $4$ legs and $2$ hornsunicorns, having $4$ legs and $1$ horn

You only know the number of animals, the number of legs and the number of horns.

Find out the number of unicorns in the magic garden.

It is guaranteed that the information provided is correct.

### Standard input

The first line contains $3$ integers $A$, $L$ and $H$ representing the number of animals, legs and horns.

### Standard output

The first line will contain the number of unicorns.

### Constraints and notes

$1 \leq A \leq 1000$ $2 \leq L \leq 4000$ $0 \leq H \leq 2000$ There will always be a solution that respects the restrictions in the input.

| Input | Output | Explanation |
| --- | --- | --- |
| 7 18 4 | 0 | There is no unicorn in the magic garden. Just $2$ rams and $5$ chickens. |
| 4 12 3 | 1 | $2$ chickens$1$ ram$1$ unicorn |
| 5 20 5 | 5 | The magic garden is the home of the $5$ unicorns. |
