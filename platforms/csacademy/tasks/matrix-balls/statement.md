# Matrix Balls

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/matrix-balls/](https://csacademy.com/contest/archive/task/matrix-balls/)  

---

You are given a matrix $A$ of size $N \times M$, containing distinct elements. Initially there is a ball placed in every cell of the matrix. Each ball follows the following movement:

If the current cell is smaller than all of its (at most $8$) neighbours, the ball stops in this cell;otherwise, the ball moves to the smallest neighbouring cell.

Find for each cell of $A$ how many balls will end up there, when all the balls stop moving.

### Standard input

The first line contains two integers $N$ and $M$.

Each of the next $N$ lines contains $M$ integers representing the elements of $A$.

### Standard output

Print $N$ lines, each containing $M$ integers. The $j^{th}$ element on the $i^{th}$ line should represent the number of balls that end up in cell $(i, j)$.

### Constraints and notes

$1 \leq N, M \leq 500$ $0 \leq A_{i, j} \leq 3*10^5$
