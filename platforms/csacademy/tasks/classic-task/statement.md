# Classic Task

**Time Limit:** `3000 ms`  
**Memory Limit:** `5120 KB`  
**Source:** [https://csacademy.com/contest/archive/task/classic-task/](https://csacademy.com/contest/archive/task/classic-task/)  

---

This problem has an unusual memory limit!

You are given a matrix $A$ of size $N \times M$. The cost of a path is defined as the sum of values of every cell in the path. Find the minimum cost path from $(1, 1)$ to $(N, M)$, given that from a certain position $(x, y)$ you may go to either $(x + 1, y)$ or $(x, y + 1)$.

You are required to print the actual path, which we've encoded as follows:

From a certain position $(x, y)$, if you want to go to $(x + 1, y)$ you should print the character $D$.From a certain position $(x, y)$, if you want to go to $(x, y + 1)$ you should print the character $R$.If there are multiple solutions, you may print any of them. 

### Standard input

The first line contains two integers, $N$ and $M$.

The $A$ matrix is encoded as follows:

You are given an array $U$ of $N$ integers, on the second line.You are also given an array $V$ of $M$ integers, on the third line.$A_{i, j} = (U_i + j) \ \text{xor}\ (V_j + i)$, for every $1 \leq i \leq N, 1 \leq j \leq M$.By $\text{xor}$ we are referring to the bitwise-xor operator.

### Standard output

Print a string consisting only of $D$'s and $R$'s, denoting the minimum cost path path.

### Constraints and notes

$1 \leq N, M \leq 10^4$ $0 \leq U_i < 2^{30}$, for every $1 \leq i \leq N$ $0 \leq V_j < 2^{30}$, for every $1 \leq j \leq M$ If there are multiple solutions, you may print any of them.
