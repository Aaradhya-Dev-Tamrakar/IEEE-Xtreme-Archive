# Odd Pair Sums

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/odd-pair-sums/](https://csacademy.com/contest/archive/task/odd-pair-sums/)  

---

You are given an array of $N$ integers. You want to eliminate the minimum number of elements such that in the resulting array the sum of any two adjacent values is odd.

### Standard input

The first line contains a single integer $N$.

The second line contains the $N$ elements of the array.

### Standard output

Print a single integer representing the minimum number of elements you need to eliminate.

### Constraints and notes

$1 \leq N \leq 10^5$ The elements of the array are integers between $0$ and $10^9$

| Input | Output |
| --- | --- |
| 3<br>1 2 3 | 0 |
| 5<br>1 3 5 4 2 | 3 |
| 10<br>5 9 2 5 3 3 4 6 4 1 | 5 |
