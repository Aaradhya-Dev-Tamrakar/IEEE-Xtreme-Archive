# Beautiful Matrix

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/beautiful-matrix/](https://csacademy.com/contest/archive/task/beautiful-matrix/)  

---

You are given a matrix $A$ of size $N \times M$.  We define matrix $B$ of size $(N - 1) \times (M - 1)$ in the following way:

$B[i][j] = A[i][j] + A[i + 1][j] + A[i + 1][j + 1] + A[i][j + 1]$ for $1 \leq i < N$ and $1 \leq j < M$

The beauty of a matrix is defined as the sum of the values in the matrix.

You are allowed to swap any $2$ rows or any $2$ columns of matrix $A$.

You want to compute the maximum beauty of matrix $B$ after performing at most $1$ swap. (*Note* that you may choose not to perform any swaps)

### Standard input

The first line contains two integers $N$ and $M$.

Each of the next $N$ lines contains $M$ integers representing the elements of $A$.

### Standard output

Print a single integer representing the maximum beauty of matrix $B$.

### Constraints and notes

$2 \leq N$ $2 \leq M$ $N * M \leq 3*10^5$ $-1000 \leq A_{i, j} \leq 1000$
