# Subarray Partition

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/subarray-partition/](https://csacademy.com/contest/archive/task/subarray-partition/)  

---

You are given an array $A$ of $N$ integers. Partition $A$ in the maximum number of subarrays such that all the numbers having the same value are in the same subarray.

### Standard input

The first line contains a single integer $N$.

The second line contains the $N$ elements of the array.

### Standard output

Print a single number representing the maximum number of subarrays.

### Constraints and notes

$1 \leq N \leq 10^5$ $1 \leq A_i \leq 10^5$

| Input | Output |
| --- | --- |
| 4<br>1 2 2 1 | 1 |
| 4<br>1 2 3 4 | 4 |
| 4<br>1 1 2 2 | 2 |
