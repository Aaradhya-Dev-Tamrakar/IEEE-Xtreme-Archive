# Numbers Game

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/numbers-game/](https://csacademy.com/contest/archive/task/numbers-game/)  

---

Alex is playing a game where he writes down positive integers having exactly $2$ digits. For every pair of adjacent numbers $a$ and $b$, the last digit of $a$ should be equal to the first digit of $b$. Count the number of pairs that don't respect this property.

### Standard input

The first line contains a single integer $N$.

The second line contains the $N$ integers Alex wrote down.

### Standard output

Print the answer on the first line.

### Constraints and notes

$2 \leq N \leq 1000$

| Input | Output |
| --- | --- |
| 7<br>89 93 48 80 72 24 18 | 3 |
