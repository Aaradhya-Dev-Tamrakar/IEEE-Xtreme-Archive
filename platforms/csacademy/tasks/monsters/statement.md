# Monsters

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/monsters/](https://csacademy.com/contest/archive/task/monsters/)  

---

### Description

Humans finally landed on one of the Centaurus Constellation planets. A big surprise (or not!): the planet is inhabited by monsters! The monsters' defence system is composed of battle cells, arranged in the form of a matrix with $N$ rows and $M$ columns.

Our intergalactic army has already attacked some of the cells, but now it is your turn to destroy exactly one cell.

By definition, the strength of the monsters’ defence system is equal to the number of submatrices (possibly overlapping) that contain only intact cells. A submatrix is a non-empty matrix obtained from the original matrix by eventually removing:

Some consecutive rows, starting from the first one;Some consecutive rows, ending at the last one;Some consecutive columns, starting from the first one;Some consecutive columns, ending at the last one.

Select a cell to be destroyed by you in a way that minimizes the strength of the defence system.

### Task

Develop a program to calculate the strength of the defence system after your attack.

### Input

The first line of the standard input contains two space separated integers $N$ and $M$ representing the number of rows, and the number of columns, respectively.

Each of the next $N$ lines contains a binary string of size $M$, representing the cells of the matrix. A $1$ corresponds to an intact cell, while a $0$ corresponds to a cell already destroyed by our army.

### Output

Write on the single line of the standard output the strength of the defence system after your attack.

### Constraints and subtasks

Subtask 1 (12 points): $1 \leq N, M \leq 50$.Subtask 1 (16 points): $1 \leq N, M \leq 200$.Subtask 1 (27 points): $1 \leq N, M \leq 500$.Subtask 1 (45 points): $1 \leq N, M \leq 750$.There is at least one intact cell in the defence system.
