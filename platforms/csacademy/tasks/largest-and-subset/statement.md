# Largest And Subset

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/largest-and-subset/](https://csacademy.com/contest/archive/task/largest-and-subset/)  

---

You are given a set of $N$ integers. Find the maximum bitwise and value (operator &) of a subset of exactly $K$ elements.

### Standard input

The first line contains two integers $N$ and $K$.

The second line contains the $N$ elements of the set.

### Standard output

Output a single integer, representing the maximum bitwise and value.

### Constraints and notes

$1 \leq K \leq N \leq 10^5$ The elements of the set are integers between $0$ and $10^9$.
