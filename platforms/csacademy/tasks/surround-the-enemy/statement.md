# Surround the Enemy

**Time Limit:** `1500 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/surround-the-enemy/](https://csacademy.com/contest/archive/task/surround-the-enemy/)  

---

Consider a matrix of dimensions $H \times W$. There's an enemy in cell $(sx, sy)$ which can move in the 8 directions. You want to build a wall such that the enemy can't escape the matrix (get out of bounds). You can build a wall in cell $(i, j)$ with a $cost = A_{i, j}$.

Find out the minimum cost such that the enemy can't escape the matrix.

Note that you're not allowed to build a wall in cell $(sx, sy)$.

### Standard input

The first line contains four integers $H$, $W$, $sx$ and $sy$.

Each of the next $H$ lines contains $W$ integers, the values of matrix $A$.

### Standard output

The first line should contain the answer to the problem

### Constraints and notes

$3 \leq H \leq 150$ $3 \leq W \leq 150$ $1 < sx < H$ $1 < sy < W$ $0 \leq A_{i, j} \leq 10^9$ and $A_{sx, sy} = -1$
