# Template Addition

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/template-addition/](https://csacademy.com/contest/archive/task/template-addition/)  

---

This task uses an enforced template.

Implement a function that takes two integer arguments $A$ and $B$ and returns their sum.

### Standard input

The code template reads on the first line a single integer $T$, representing the number of tests that follow.

Each of the next $T$ lines contains two integers $A$ and $B$.

### Standard output

The template calls your function and prints the result of each test on a distinct line.

### Constraints and notes

The result fits on a $32$ bit signed integer

| Input | Output |
| --- | --- |
| 2<br>10 20<br>-5 5 | 30<br>0 |
| 2<br>-1234 5678<br>22224444 44442222 | 4444<br>66666666 |
