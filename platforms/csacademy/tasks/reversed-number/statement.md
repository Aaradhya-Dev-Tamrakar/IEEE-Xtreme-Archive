# Reversed Number

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/reversed-number/](https://csacademy.com/contest/archive/task/reversed-number/)  

---

You are given a number $X$.

Print 1 if the number $X$ is strictly less than the number formed by reversing $X$'s digits in base $10$, or 0 otherwise.

### Standard input

The first line contains an integer $X$.

### Standard output

Print the answer on the first line.

### Constraints and notes

$1 \leq X < 10^8$ $X$ is given in base $10$ and its last digit is not $0$

| Input | Output | Explanation |
| --- | --- | --- |
| 39 | 1 | $39$ is less than 93 |
| 65 | 0 | $65$ is not less than $56$ |
