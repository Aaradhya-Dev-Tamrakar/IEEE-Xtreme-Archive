# Single Digit Numbers

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/single-digit-numbers/](https://csacademy.com/contest/archive/task/single-digit-numbers/)  

---

You are given two integer values $A$ and $B$. Count the number of integers in the interval $[A, B]$ that contain a single distinct digit.

### Standard input

The first line contains  two integers $A$ and $B$.

### Standard output

Output a single integer representing the number of values in the inteval $[A, B]$ containing a single distinct digit.

### Constraints and notes

$1 \leq A \leq B \leq 10^6$

| Input | Output | Explanation |
| --- | --- | --- |
| 5 11 | 6 | $\{5, 6, 7, 8, 9, 11\}$ |
| 10 100 | 9 | $\{11, 22, 33, 44, 55, 66, 77, 88, 99\}$ |
| 100 456 | 4 | $\{111, 222, 333, 444\}$ |
