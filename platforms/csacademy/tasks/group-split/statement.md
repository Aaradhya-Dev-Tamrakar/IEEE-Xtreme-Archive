# Group Split

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/group-split/](https://csacademy.com/contest/archive/task/group-split/)  

---

You have $N$ chocolates. You should split them in two nonempty groups such that the size of the first group is a divisor of the size of the second group. Count the number of ways to achieve this.

### Standard input

The first line contains a single integer $N$.

### Standard output

Print the answer on the first line.

### Constraints and notes

$2 \leq N \leq 10^9$

| Input | Output | Explanation |
| --- | --- | --- |
| 6 | 3 | We can split the chocolates in groups of sizes:$1$ and $5$ $2$ and $4$ $3$ and $3$ |
| 10 | 3 | $1$ and $9$ $2$ and $8$ $5$ and $5$ |
