# 0-K Multiple

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/0-k-multiple/](https://csacademy.com/contest/archive/task/0-k-multiple/)  

---

You are given an integer $N$ and a digit $K$. Find the smallest multiple of $N$ that consists only of digits $K$ and $0$.

### Standard input

The first line contains two integers $N$ and $K$.

### Standard output

Print the result on a single line.

### Constraints and notes

$1 \leq N \leq 10^5$ $1 \leq K \leq 9$ 

| Input | Output |
| --- | --- |
| 5 2 | 20 |
| 7 4 | 4004 |
| 13 7 | 7007 |
