# LIS Generator

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/lis_generator/](https://csacademy.com/contest/archive/task/lis_generator/)  

---

### Solution

You are given an integer number $K$. You should find an array containing at most $100$ elements that has exactly $K$ longest increasing subsequences.

### Standard input

The first line contains a single integer value $K$.

### Standard output

Output a single line containing at most $100$ integers, representing your chosen array.

### Constraints and notes

$1 \leq K \leq 10^9$The values of the array should be integers between $1$ and $10^9$You should consider strictly increasing subsequences

| Input | Output |
| --- | --- |
| 1 | 3 |
| 5 | 5 4 3 2 1 |
