# Tournament Cycle

**Time Limit:** `2000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/tournament-cycle/](https://csacademy.com/contest/archive/task/tournament-cycle/)  

---

Find the number of tournament graphs with $N$ nodes that contain at least one simple cycle of length $K$.

### Standard input

The first line contains two integers $N$ and $K$.

### Standard output

Print a single integer representing the number of tournaments modulo $10^9+7$.

### Constraints and notes

$3 \leq K \leq N \leq 5000$

| Input | Output |
| --- | --- |
| 3 3 | 2 |
| 4 3 | 40 |
| 4 4 | 24 |
| 5 3 | 904 |
| 5 5 | 544 |
