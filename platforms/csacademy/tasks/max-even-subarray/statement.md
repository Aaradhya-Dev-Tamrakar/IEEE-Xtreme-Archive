# Max Even Subarray

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/max-even-subarray/](https://csacademy.com/contest/archive/task/max-even-subarray/)  

---

You are given an array of $N$ elements. Find the subarray of maximum sum having even length.

### Standard input

The first line contains a single integer $N$.

The second line contains $N$ integers representing the elements of the array.

### Standard output

Print a single integer representing the maximum sum of an even length subarray.

### Constraints and notes

$2 \leq N \leq 10^5$ The elements of the array are integers between $-10^9$ and $10^9$ 

| Input | Output | Explanation |
| --- | --- | --- |
| 3<br>1 2 3 | 5 | $[2, 3]$ |
| 5<br>1 -4 2 -16 8 | -2 | $[-4, 2]$ |
| 5<br>8 9 -8 9 10 | 20 | $[9, -8, 9, 10]$ |
