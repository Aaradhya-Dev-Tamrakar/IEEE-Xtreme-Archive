# Min Coin Payment

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/min-coin-payment/](https://csacademy.com/contest/archive/task/min-coin-payment/)  

---

You have an unlimited number of coins worth $1$, $5$ and $50$ dollars. What's the minimum number of coins you need to pay exactly $K$ dollars?

### Standard input

The first line contains a single integer $K$.

### Standard output

Print a single integer representing the minimum number of coins needed.

### Constraints and notes

$1 \leq K \leq 1000$

| Input | Output | Explanation |
| --- | --- | --- |
| 13 | 5 | You can pay $13$ dollars using coins worth $1, 1, 1, 5, 5$ |
| 25 | 5 | You can pay $25$ dollars using coins worth $5, 5, 5, 5, 5$ |
| 31 | 7 | You can pay $31$ dollars using coins worth $1, 5, 5, 5, 5, 5, 5$ |
