# Integer Coords

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/integer-coords/](https://csacademy.com/contest/archive/task/integer-coords/)  

---

Given two integers $N$ and $M$, consider the set $S$ of points having the x coordinate an integer between $0$ and $N$, and the y coordinate an integer between $0$ and $M$.

Count the number of ways of choosing two points from $S$ such that the segment determined by them contains exactly $K$ points from $S$ (including the two end points).

### Standard input

The first line contains three integers $N$, $M$ and $K$.

### Standard output

Print the answer on the first line.

### Constraints and notes

$2 \leq K \leq 50$ $1 \leq N, M \leq 50$ 

| Input | Output |
| --- | --- |
| 1 1 2 | 6 |
| 2 2 3 | 8 |
