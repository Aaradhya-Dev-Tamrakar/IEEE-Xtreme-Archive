# Circular Shift Sort

**Time Limit:** `2000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/circular_shift_sort/](https://csacademy.com/contest/archive/task/circular_shift_sort/)  

---

You are given a matrix with $N$ rows and $M$ columns. The rows and columns are 0-indexed. Each integer value between $0$ and $N * M - 1$ appears in the matrix exactly once. The matrix is considered to be sorted if the elmenent on row $i$ and column $j$ is equal to $i * M + j$.

You can perform a single type of operation: choose a row/column and permute it circulary some number of positions. You should sort the matrix.

### Standard input

The first line contains a two integer values $N$ and $M$.

Each of the next $N$ lines contains $M$ integers representing the elements of the matrix.

### Standard output

In case there is no solution output $-1$.

Otherwise the output should contain several lines, each one describing a single operation. A line should contain a character followed by two integers:

The character should be either $R$ or $C$, indicating whether the operation is performed on a row or a column. The first integer should be the index of the row/column.The second integers represents the numbers of positions the row/column is shifted. If the number is positive a row is shifted to the right (otherwise to the left) and a column is shifted down (otherwise up).

### Constraints and notes

$2 \leq N, M \leq 300$You should output at most $5*10^5$ lines.

| Input | Output |
| --- | --- |
| 2 2<br>1 3<br>2 0 | C 1 -1<br>R 0 1 |
| 3 4<br>6 5 0 4<br>2 9 7 11<br>8 3 10 1 | C 1 -1<br>R 2 3<br>C 0 -1<br>R 2 -3<br>C 3 1<br>C 1 -1<br>R 1 1<br>R 0 -2 |
| 3 3<br>6 7 3<br>1 5 2<br>4 0 8 | -1 |

We have an interactive task simulator that you can control by dragging lines and columns in a matrix.
