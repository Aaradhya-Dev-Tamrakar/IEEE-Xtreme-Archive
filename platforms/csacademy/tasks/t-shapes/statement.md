You are given a matrix with $N$ rows and $M$ columns. The elements of the matrix are lowercase letters of the English alphabet. We call a $T$-shape  a set of $5$ cells, all containing the letter $t$, and displayed like below:

  XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX  

Count the number of $T$-shapes in the matrix.

### Standard input

The first line contains two integers $N$ and $M$.

Each of the following $N$ contains $M$ characters, representing the matrix values.

### Standard output

Output a single integer, representing the number of $T$-shapes.

### Constraints and notes

$1 \leq N, M \leq 200$The $T$-shapes can overlap

| Input | Output |
| --- | --- |
| 3 3<br>ttt<br>ztt<br>atb | 1 |
| 5 5<br>ttttt<br>ztttz<br>ttttt<br>astta<br>dttts | 6 |
