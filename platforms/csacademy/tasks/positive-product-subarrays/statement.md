# Positive Product Subarrays

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/positive-product-subarrays/](https://csacademy.com/contest/archive/task/positive-product-subarrays/)  

---

You are given an array of $N$ integers where each element is a digit. Count how many subarrays have the product of the elements strictly greater than $0$.

### Standard input

The first line contains a single integer $N$.

The second line contains $N$ digits representing the elements of the array.

### Standard output

Output a single number representing the number of valid subarrays.

### Constraints and notes

$1 \leq N \leq 10^5$

| Input | Output |
| --- | --- |
| 5<br>1 1 2 3 5 | 15 |
| 6<br>1 0 2 0 3 0 | 3 |
| 7<br>0 1 2 3 0 4 5 | 9 |
