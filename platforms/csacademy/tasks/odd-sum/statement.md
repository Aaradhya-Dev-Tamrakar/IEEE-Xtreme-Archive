# Odd Sum

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/odd-sum/](https://csacademy.com/contest/archive/task/odd-sum/)  

---

You are given an array $A$ of $N$ integers. Count the number of ways you can choose a pair $(i, j)$, $1 \leq i <j \leq N$, $i \neq j$, such that $A_i + A_j$ is odd.

### Standard input

The first line contains a single integer $N$.

The second line contains $N$ integers representing the elements of $A$.

### Standard output

Print the answer on the first line.

### Constraints and notes

$1 \leq N \leq 100$ $1 \leq A_i \leq 100$ 

| Input | Output |
| --- | --- |
| 4<br>1 2 3 4 | 4 |
| 4<br>1 1 3 3 | 0 |
| 5<br>1 1 1 2 2 | 6 |
