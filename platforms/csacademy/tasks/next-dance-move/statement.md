# Next Dance Move

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/next-dance-move/](https://csacademy.com/contest/archive/task/next-dance-move/)  

---

You've just learned a new dance, SalsaJS. It consists of $4$ moves and goes like this:

$1, 2, 3, 1, 2, 3, 1, 2, 3, 4$

After that, you just keep repeating the sequence above.

What's the $Nth$ dance move that you need to do, if you're dancing SalsaJS indefinetly?

### Standard input

The integer $N$.

### Standard output

A number between $1$ and $4$, corresponding with the $Nth$ dance move.

### Constraints and notes

$N$ fits in a signed 32 bit integerSalsaJS will become a Javascript library in 32 minutes after this task goes live.

| Input | Output |
| --- | --- |
| 1 | 1 |
| 3 | 3 |
