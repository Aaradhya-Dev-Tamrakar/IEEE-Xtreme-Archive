# Div 3

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/div-3/](https://csacademy.com/contest/archive/task/div-3/)  

---

You are given a positive integer $X$. You are allowed to perform one of the following three operations:

Decrement $X$ by $1$.Increment $X$ by $1$.If $X$ is a multiple of $3$ you can divide $X$ by $3$.

Find the minimum number of operations needed to make $X$ equal to $1$.

### Standard input

The first line contains a single integer $X$.

### Standard output

Print the answer on the first line.

### Constraints and notes

$1 \leq X \leq 10^9$ 

| Input | Output | Explanation |
| --- | --- | --- |
| 4 | 2 | Decrement $X$ by $1$ and after divide it by $3$. |
| 8 | 3 | Increment $X$ by $1$ and after divide it by $3$ two time. |
