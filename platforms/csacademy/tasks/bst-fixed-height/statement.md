# BST Fixed Height

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/bst-fixed-height/](https://csacademy.com/contest/archive/task/bst-fixed-height/)  

---

Find the number of binary search trees with $N$ nodes and height exactly $H$.

### Standard input

The first line contains two integers $N$ and $H$.

### Standard output

Print a single value representing the result modulo $10^9+7$.

### Constraints and notes

$1 \leq H \leq N \leq 500$

| Input | Output | Explanation |
| --- | --- | --- |
| 3 3 | 4 |  |
| 4 3 | 6 |  |
| 5 3 | 6 |  |
| 5 4 | 20 |  |
