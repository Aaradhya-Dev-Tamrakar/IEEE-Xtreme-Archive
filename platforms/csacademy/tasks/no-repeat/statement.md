# No Repeat

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/no-repeat/](https://csacademy.com/contest/archive/task/no-repeat/)  

---

You are given a string $S$ of size $N$. Find the first character of $S$ that occurs only once in the entire string. If there is no such character, output $-1$.

### Standard input

The first line contains an integer $N$.

The second line contains $S$.

### Standard output

Print the answer on the first line.

### Constraints and notes

$1 \leq N \leq 100$ $S$ consists of lowercase letters of the English alphabet

| Input | Output |
| --- | --- |
| 7<br>nothotn | h |
| 6<br>ccaabb | -1 |
