# Missing Number

**Time Limit:** `1000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/missing-number/](https://csacademy.com/contest/archive/task/missing-number/)  

---

You are given an array of $N$ positive integers. Find the smallest positive number that doesn't occur in the array.

### Standard input

The first line contains a single integer $N$.

The second line contains the $N$ elements of the array.

### Standard output

Print the answer on the first line.

### Constraints and notes

$1 \leq N \leq 1000$ $1 \leq A_i \leq 1000$ 

| Input | Output |
| --- | --- |
| 4<br>1 3 2 5 | 4 |
| 4<br>6 5 1 2 | 3 |
