# Interactive Partial Sums

**Time Limit:** `2000 ms`  
**Memory Limit:** `128 MB`  
**Source:** [https://csacademy.com/contest/archive/task/interactive-partial-sums/](https://csacademy.com/contest/archive/task/interactive-partial-sums/)  

---

You are given an array of $N$ integers. After reading each element of the array, output the sum of all the elements read so far.

### Interaction

First you should read a single integer $N$.

Then you should read the elements of the array one by one. After each number read output and flush the sum of all the numbers read so far, followed by a newline character.

Warning: In order to read the next element of the array you are required to print your answer first.

Warning2: Don't forget to add a newline before flushing the output.

### Constraints and notes

This task is NOT adaptive.$1 \leq N \leq 20000$The elements of the array are integer between $0$ and $10^9$.
