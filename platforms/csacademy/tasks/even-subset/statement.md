# Even Subset

**Time Limit:** `1000 ms`  
**Memory Limit:** `256 MB`  
**Source:** [https://csacademy.com/contest/archive/task/even-subset/](https://csacademy.com/contest/archive/task/even-subset/)  

---

You are given an array $A$ of $N$ elements. Choose a (possibly empty) subsequence containing an even number of elements that have maximum sum.

### Standard input

The first line contains a single integer $N$.

The second line contains $N$ integers representing the elements of $A$.

### Standard output

Print the sum of the elements of the chosen subsequence on the first line.

### Constraints and notes

$2 \leq N \leq 10^5$ $-10^{9} \le A_i \le 10^{9}$

| Input | Output |
| --- | --- |
| 3<br>1 2 3 | 5 |
| 4<br>0 5 3 8 | 16 |
| 3<br>-1 -2 -1 | 0 |
